# CNC-Master

Free tools for people who write and run NC programs – CNC programmers, machinists and small shops.

| | |
|---|---|
| **[gEdit](https://cnc-master.xyz/en/gedit/)** | Editor for NC code: read, check, clean up and renumber programs. Fanuc, Heidenhain, Okuma, Sinumerik. |
| **[NCView](https://github.com/CNC-Master-xyz/NCView)** | Fast, simple viewer for G-code. Open, read, close. |

📖 **[CNC-Master Academy](https://cnc-master.xyz/en/academy/)** – G-code basics and reference tables for Fanuc, Heidenhain, Hurco and Okuma.

All tools are free and open source and work offline. 
Questions or a wrong code in a table? Open an issue or write to info@cnc-master.xyz.
